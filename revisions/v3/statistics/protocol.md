# Revision-added exploratory statistics protocol

Frozen before this revision's subgroup, threshold, or new-encoder effectiveness calculations (2026-10-03 UTC). Historical v1.0.0 results, including the QASPER 195-question joint sensitivity and primary BM25 gaps, were already known. This is not the original preregistration.

## Fixed scope

Use all 875 QASPER questions and 209 SciFact pairs, their original candidate universes, source IDs, complete frozen rankings, and original connected cluster labels. Preserve every historical output. The original five methods are BM25, TF-IDF, MiniLM (`dense`), lead, and random. Add the complete, separately frozen Qwen3 run only when all 1,084 rankings exist; never analyze a selected partial run.

1. QASPER exact normalized answer agreement uses the adapter's existing Boolean rule, not semantic agreement. Report agreement, its complement, and full cohort for each method at original primary k=5. Show item and represented-paper counts, four mutually exclusive topology counts, original C−A, minimal-reference-pruned C−A, and paired within-item pruned-minus-original change. Use 10,000 item-weighted paper-cluster bootstrap draws, seed 20261002, resampling represented clusters within each reported cohort. Shared papers across the two subsets are not independent; no between-subset causal contrast is estimated. Verify weighted subset reconstruction. Check pruning's monotonicity for every complete ranking through the finite event depths. Do not assert best-reference F1 invariance.
2. For each method and corpus report exact smallest uniform integer unit and lexical-token budgets achieving 0.50, 0.75, and 0.90 annotation completion under C and A. Derive these from the full individual completion-cost distribution, which is equivalent to checking every possible integer budget. Token prefixes include complete units only and stop at the first unaffordable unit, using the historical max(1, lexical token count) cost. Saturated short candidates remain in the denominator. These are population threshold budgets, not mean individual additional cost.
3. Bootstrap both C and A budgets and their difference using the identical original cluster draws (10,000, seed 20261002). Each draw keeps every item of each sampled cluster and uses its resulting item denominator. Retain unattained thresholds as +infinity, count them explicitly, and never extrapolate; if a paired gap is undefined because either endpoint is unattained, identify it rather than silently discarding the draw. Full finite rankings make all prespecified point and bootstrap thresholds attainable here. Discrete-statistic percentile endpoints use the usual linear interpolation; endpoints need not themselves be attainable integer budgets.
4. Report means/cluster intervals, medians, quartiles, 90th/95th percentiles, maxima, and zero shares for depth and token cost. Also describe positive-cost items and their represented clusters; conditional intervals are descriptive and resample only clusters represented in that affected-item subset.
5. Fixed finite paired method comparisons: MiniLM−BM25, Qwen3−BM25, and Qwen3−MiniLM, across all six original k values {1,2,3,5,10,20}, for C, A, best-reference F1, union F1, C−A, and the change from a C advantage to an A advantage. The latter is (C_left−C_right)−(A_left−A_right), algebraically equal to the C−A contrast and recorded explicitly. Report all pointwise intervals; make no multiplicity-controlled significance or reversal claim. Add full primary/curve/cost summaries for Qwen3; recompute method/ranking/scoring-point totals.

## Validation

Validate full valid candidate permutations, exact item/cluster/gold identity, original stored score and cost replay, nonempty families, A≤C≤H, one-distinct-set C=A, four-way BM25 category totals, exhaustive/disjoint topology, subgroup weighted reconstruction, C and d_C invariance under pruning, union shrinkage, A nondecrease, H nonincrease, gap nonincrease, paired bootstrap weights, saturation, empty strata, unreachable thresholds, and a counterexample to best-reference-F1 invariance. New output is exclusively under revisions/v3/statistics. Original files are read-only.
